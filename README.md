This extension offers a streamlined way to uninstall Flatpaks and AppImages through right-clicking on the app icon. The main driver was application management on an immutable distro.
The code was built using Google Gemini and could likely be further refined, but it works as intended.

To Install:
Download and extract the contents to right-click-uninstall@user.local.
Run the included install.sh, followed by logging out and back in before enabling the extension.
